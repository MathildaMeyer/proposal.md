# Title
Galaxia 2.0: Interactive Cosmic Generative Art

## Repository
[Link to Repository] https://github.com/MathildaMeyer/proposal.md.git 

## Description
Galaxia 2.0 will create mesmerizing generative art inspired by celestial phenomena, utilizing dynamic algorithms to mimic cosmic motion and interaction. This project aligns with media and digital arts by blending technology and artistry into a captivating visual experience.

## Features
- **Dynamic Generative Algorithm**
  - Develop algorithms that simulate movements of celestial bodies, such as stars, planets, and nebulas, adapting to user inputs for personalized cosmic experiences.
- **Interactive Controls**
  - Design an intuitive interface allowing users to adjust parameters like speed, color schemes, and celestial density to create unique visual outputs.
- **Export and Sharing**
  - Include functionality for users to save cosmic scenes as high-resolution images or short video loops, enabling them to share their creations.

## Challenges
- Explore advanced programming techniques for real-time rendering and seamless interactivity.
- Study celestial physics and aesthetics to ensure authenticity in visual representations.
- Research optimization strategies for efficient performance on various devices.

## Outcomes
### Ideal Outcome:
The project produces intricate cosmic generative art that responds fluidly to user inputs and offers both visual beauty and technical sophistication.

### Minimal Viable Outcome:
The program generates basic celestial visuals with limited interactivity but effectively demonstrates the concept of cosmic generative art.

## Milestones
- **Week 1**
  1. Research celestial motion and generative art principles.
  2. Set up repository and basic coding framework.

- **Week 2**
  1. Develop initial algorithms for celestial motion.
  2. Test visual outputs and refine designs.

- **Week 3 (Final Week)**
  1. Integrate interactive controls and optimize performance.
  2. Finalize export functionality and presentation materials.
